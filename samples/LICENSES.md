# Sample licences

Every recording shipped in `samples/` is listed here with its origin and licence. Keep this file
up to date when adding sounds.

## Tabla strokes (`samples/tabla/`)

Source: the sample set bundled with [Sonic Pi](https://github.com/samaaron/sonic-pi) under
`etc/samples/`, which its licence file states are individually dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Sonic Pi's samples README credits
them to Freesound user mmiron (uploaded under the earlier username dio_333). Retrieved 2026-11-12 from
`https://raw.githubusercontent.com/samaaron/sonic-pi/dev/etc/samples/`.

CC0 requires no attribution; the credit here is a courtesy and a provenance record.
